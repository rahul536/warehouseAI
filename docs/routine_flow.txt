warehouse_agent.py is essentially the AI orchestration layer, while wms_tools.py is the data-access layer.

So the clean mental model is:

User → UI/CLI → AI Agent → Tool Router → WMS Tools → Database → Tool Result → AI → Answer

And for a shortage investigation:

AI → investigate_order_shortage() → Allocation → Shortage Item → Inventory → Movements → Root Cause → AI → Answer
